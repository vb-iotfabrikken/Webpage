# Cursor rules for this project

## Language

All content, code, UI text, filenames, URL slugs, identifiers, comments,
commit messages, and chat/assistant responses MUST be in English.

Do not introduce Danish (or any other non-English) text anywhere — neither
in source code, content files, configuration, nor in replies. If Danish
content is encountered in existing files, translate it to English as part
of the change.

## General

- Keep changes small and focused.
- Prefer Astro and Tailwind best practices.
- Avoid adding dependencies unless necessary.
