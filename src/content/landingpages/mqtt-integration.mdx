MQTT is the most widely used protocol for sending IoT data between systems. It is lightweight, real-time, and supported by every major BMS, SCADA and data-warehouse platform. That's why it is our preferred route when customers want **RoomAlyzer data directly in their own systems**.

## How it works

1. You get a TLS endpoint, a username and a certificate from us.
2. You subscribe to the topics you care about — or the whole tree.
3. Your system receives a message each time a sensor reports in.

No polling, no lag, and no bespoke development.

## What do customers use it for?

- Push CO₂ and presence data into BMS to run ventilation on demand.
- Stream indoor-climate data into Power BI or Tableau for ESG reporting.
- Trigger tickets in ServiceNow or TOPdesk when a sensor goes into alarm.
- Feed ML models with historic and real-time data on the same channel.

## Typical payload

```json
{
  "time": "2026-04-22T08:14:31Z",
  "tenant": "municipality-x",
  "building": "north-school",
  "device": "class-2a-sensor",
  "type": "co2",
  "value": 847,
  "unit": "ppm"
}
```
