# Events registry

Live fair data and helpers for the `/events/` hub, landing pages, and redirects.

**Authoritative rules:** `.cursor/rules/project-rules.mdc` (Events hub and landing pages).

**Structural template:** [`EventLandingLayout.astro`](../components/events/EventLandingLayout.astro) —
not any single fair page (those are temporary).

## Live vs archive

| Layer | Purpose |
|-------|---------|
| **Live** | `siteEvents` rows with `startDate` / `endDate`; hub cards; landing + contact pages |
| **Template** | `EventLandingLayout`, `EventCardActive`, `eventCardThemes` |
| **Archive** | [`archive/events/`](../../archive/events/) — snapshots after retirement |

Events hide from the hub when `asOf > endDate + EVENT_ARCHIVE_GRACE_DAYS`, or when
`status: "archived"`.

## Registry fields (`SiteEvent`)

| Field | Description |
|-------|-------------|
| `slug` | URL segment under `/events/{slug}/` |
| `hostLocale` | Locale that shows Card 1 (active) |
| `detailLocales` | Locales with a landing + contact page (usually `[hostLocale]`) |
| `startDate` / `endDate` | ISO dates (`YYYY-MM-DD`); hub sort + live filter |
| `status` | Optional `"archived"` to force-hide |
| `moduleTeasers` | Optional module route keys (e.g. `modules/indoor-climate`) |

Also register in `eventAssets`: `logo`, `logoAlt`, `cardTheme`, `officialUrl`.

Set `logoPreset` on the theme in `eventCardThemes.ts` — see [`eventCardLogo.ts`](../eventCardLogo.ts)
(`rectangle`, `rectangleLg`, `roundel`, `bleed`). Do not add per-page logo shell classes.

## Adding an event

1. Add `siteEvents` row + `eventAssets` (+ new `cardTheme` in `eventCardThemes.ts` if needed).
2. Add hub copy in `src/data/i18n/events.ts` (Card 1 + Card 2 per locale).
3. Create landing copy `src/data/i18n/{event}.ts` and images under `public/images/events/{slug}/`.
4. Add thin pages using `EventLandingLayout` + `getEventStaticPaths(slug)`:
   - `src/pages/[lang]/events/{slug}.astro`
   - `src/pages/[lang]/contact/{slug}.astro`
5. Set `detailLocales` to include the host locale.
6. Foreign-locale redirects are generated by `getEventRedirectMap()` in `astro.config.mjs`.
7. Optional: `moduleTeasers` for module-page promotion.

## Retiring an event

1. After the fair (+ grace days), add `{ slug, hostLocale }` to `archivedEvents`.
2. Set `status: "archived"` on the `siteEvents` row (or remove the row after snapshot).
3. Remove hub copy from `i18n/events.ts`.
4. Snapshot sources to `archive/events/{slug}/` (see `archive/events/_template/`).
5. Build and verify:
   - Hub has no card for the slug
   - `/de/events/{slug}/` → `/de/events/` (301)
   - `/de/contact/{slug}/` → `/de/contact/` (301)

## Key helpers

| Function | Use |
|----------|-----|
| `isEventLive(event)` | Hub, teasers, static paths |
| `getActiveEventsForLocale(lang)` | Card 1 list |
| `getNewsEventsForLocale(lang)` | Card 2 list |
| `getEventStaticPaths(slug)` | Landing + contact `getStaticPaths` |
| `getModuleEventTeaser(slug, moduleKey, lang)` | Module hero teasers |
| `getEventRedirectMap()` | `astro.config.mjs` redirects |

## Fair recap section

The photo block at the bottom of event landing pages uses `pastFairRecap` in
`src/data/i18n/eventFairRecap.ts`. Set `startDate`, `endDate`, `city`, and
`eventName` once when the recap fair changes — the eyebrow and date phrases are
derived automatically (no relative wording like “two weeks ago”).
